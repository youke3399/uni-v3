# Uniswap V3 监听器使用说明

## 功能介绍

本项目是一个用于监听 Uniswap V3 交易对事件的服务，能够实时捕获池子创建、交易、流动性变动等事件，方便用户进行数据分析和策略开发。

## 依赖安装

请确保已安装 Node.js（建议版本 16 及以上）和 npm。然后在项目根目录下执行：

```bash
pnpm install
```

安装所有依赖包。

## 环境变量配置

请在项目根目录创建 `.env` 文件，配置以下环境变量：

```
RPC_URL=<你的以太坊节点RPC地址>
START_BLOCK=<监听起始区块号>
DATABASE_URL=<数据库连接字符串>
```

- `RPC_URL`：用于连接以太坊网络的节点地址，例如 Infura、Alchemy 等服务提供的 URL。
- `START_BLOCK`：监听开始的区块高度，建议设置为项目部署时的最新区块。
- `DATABASE_URL`：用于存储监听数据的数据库连接地址。

## 运行方式

### 启动监听服务

```bash
pnpm start
```

启动监听器，开始从指定区块开始监听 Uniswap V3 相关事件。

### 开发模式

```bash
pnpm dev
```

启动开发模式，支持热更新，方便调试。

### 生产模式

```bash
pnpm build
```

构建项目，生成生产环境代码。

```bash
pnpm start
```

启动生产环境监听服务。

## 目录结构

```
src/
├── index.ts          # 入口文件，启动监听服务
├── listener.ts       # 监听器核心逻辑，处理事件捕获和数据存储
├── utils.ts          # 工具函数
├── config.ts         # 配置文件，读取环境变量
└── types/            # 类型定义
```

## 注意事项

- 请确保 `RPC_URL` 的节点服务稳定，避免因连接中断导致监听失败。
- `START_BLOCK` 设置过早可能导致数据量过大，影响性能。
- 数据库配置正确，保证事件数据能够持久化存储。
- 监听过程中请勿频繁重启，避免重复处理同一区块事件。
- 如遇问题，请查看日志输出，定位错误原因。

感谢使用本监听器，祝您开发顺利！
